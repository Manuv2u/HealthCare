# Shivamogga (Shimoga) District PIN Codes — Methodology, Cross-Checks, and Gaps

## Method used
1. **Primary source: `api.postalpincode.in` (public wrapper around official India Post PIN records; district field is sourced directly from India Post's own database).**
   - Confirmed via a live query (`GET https://api.postalpincode.in/postoffice/Shimoga`) that India Post's own records use the district name **"Shimoga"** (not "Shivamogga") — 15 matches returned, all with `"District":"Shimoga"`.
   - A query for `GET https://api.postalpincode.in/postoffice/Shivamogga` returned **zero** results ("No records found"), confirming the source data does not use the "Shivamogga" spelling anywhere in the District/Office name fields.
   - Since the API has no "list all offices in a district" endpoint, every PIN code in the `577xxx` block (577001–577999, 999 codes) was queried individually via `GET https://api.postalpincode.in/pincode/{pincode}` (999 live HTTP requests, all executed in this session — no cached/prior-knowledge data used).
   - Of those 999 codes, 166 returned valid post-office records. Of the post offices in those 166 pincodes, records were filtered to `District == "Shimoga"`.
   - Result: **357 individual post-office records, 52 distinct PIN codes**, for Shimoga district.

2. **Cross-checks performed:**
   - **Count cross-check:** An independent web search snippet (not used as a data source, only as a sanity check) stated "There are a total of 357 Post Offices in Shimoga district of Karnataka." This exactly matches the 357 post-office records independently derived from the pincode-by-pincode API scan above — strong corroboration that the 577xxx range scan was complete and not missing another PIN block.
   - **Taluk HQ cross-check:** Fetched the official Government of Karnataka district website `https://shivamogga.nic.in/en/std-pin-codes/` (STD & PIN Codes page). It lists 7 taluk headquarter PIN codes: 577201 (Shivamogga), 577301 (Bhadravathi), 577401 (Sagar), 577418 (Hosanagar), 577427 (Shikaripur), 577429 (Sorab), 577432 (Thirthahalli). **All 7 are present** in the API-derived 52-pincode list, confirming range/coverage correctness.
   - **District-name field check:** Scanning all districts appearing in the 577xxx range confirmed only 4 districts share this prefix block: `Shimoga`, `Chickmagalur`, `Chitradurga`, `Davangere`. This confirms the 577xxx scan window was appropriate (no Shimoga pincode was found outside it, and no other district used "Shimoga"/"Shivamogga" as a name).

## Gaps / sources that were NOT usable in this session
- **`https://www.indiapost.gov.in/vas/pages/FindPinCode.aspx`** (the classic India Post "Find Pincode" tool URL) now **redirects to the homepage** ("Redirecting... Taking you to the homepage") — the tool appears to have been retired/relocated in a site redesign. I could not locate the replacement tool's URL within the session before the browser session became unavailable (see below), so **no direct indiapost.gov.in UI lookups were completed** for individual PIN verification. This is a genuine gap — cross-checks above rely on (a) the api.postalpincode.in bulk data and (b) the shivamogga.nic.in Karnataka-government STD/PIN page, not a direct indiapost.gov.in UI screenshot/snapshot.
- **`https://www.data.gov.in/resource/all-india-pincode-directory`** returned **HTTP 403 Forbidden** when fetched — the OGD portal resource page blocks the fetch tool used in this session. Could not obtain the raw CSV/API dataset from data.gov.in directly as a second independent bulk source.
- The Playwright browser tool used for the indiapost.gov.in UI cross-check session was **shared with another concurrent process/task** — it was found mid-task already navigated to an unrelated third-party site (metropolisindia.com), and the browser context closed unexpectedly mid-interaction. This made interactive verification against the indiapost.gov.in UI unreliable within this session; it was abandoned in favor of the corroborated api.postalpincode.in + shivamogga.nic.in cross-checks described above, which are considered sufficient (exact 357-record match, all 7 official taluk HQ codes matched).
- Minor data-quality note (not a gap, but flagged for transparency): the raw `Block`/taluk field returned by the API contains a few inconsistent spellings/typos as recorded by India Post itself (e.g. "Bhadravathi" vs "Bhadravati" vs "Bhadravathii" vs "Bhadravaathi"; "Shimoga" vs "Shimogai"; "Tirthahalli" vs "Thirthahalli" vs "Thrithahalli"; "Sorab" vs "Soraba"; "Hosanagara" vs "Hosanagar"; "Shikarpur" vs "Shikaripura"). These were normalized to a single canonical taluk label per PIN code in the output JSON (variants merged, not discarded) — the underlying raw per-office records (pre-normalization) are preserved in `shimoga_raw_records.json` in this same scratchpad directory for audit if needed.
- Two of the 357 raw post-office records had `Block: "NA"` from the source (taluk/block not populated by India Post for that specific office). In both cases the PIN code they belonged to also had other offices with a valid taluk name, so the final per-PIN-code `taluk` field is not missing any data — but it is noted here that 2 individual office-level records had no taluk value in the source data.

## Bottom line
The 52-PIN-code, 357-post-office list in `shivamogga_pincodes.json` is built entirely from live India-Post-sourced API responses fetched in this session (no training-data fill-in), and is corroborated by an independent post-office count and by the official Karnataka district government website's taluk HQ PIN list. The main unmet goal was a direct interactive cross-check against the indiapost.gov.in web UI, which was not reachable/stable in this session (see gaps above).
